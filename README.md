# Календарь учителя

## Запуск

Требуется Node.js 18 или новее.

```bash
npm install
npm run dev
```

Скопируйте `.env.example` в `.env` и заполните конфигурацию Firebase. В консоли Firebase включите Authentication → Email/Password и Cloud Firestore. После этого можно собрать приложение командой `npm run build`.

Сейчас календарь сохраняет созданные уроки в локальном хранилище браузера. Для полноценного облачного хранения нужно подключить Firebase config и заменить слой сохранения на Firestore; структура данных описана в `ИНСТРУКЦИЯ_ИИ_КАЛЕНДАРЬ_УЧИТЕЛЯ.md`.
